# ExtendedBosses — состояние и план

[English](ROADMAP.md) · **Русский**

Текущая версия: **0.8.4**. У каждого босса от Эйктюра до Фейдера есть рейдовый бой
(`FIGHTS-RU.md`). Древний прошёл первый тест в игре (правки в 0.8.2); остальные собраны и
сверены с кодом игры (`check-refs.ps1`, самопроверка `eb check`), но ещё не сыграны.

## Дальше

- [ ] Проверка каждого босса в игре с группой и с гостем без мода: фазы, щит и окно
      уязвимости, фазы-циклы, метки, угроза, награда, очистка.
- [ ] Балансный проход по итогам проверок (числа в FIGHTS-RU.md — стартовые).
- [ ] Король Льда — после просмотра его ванильного боя в игре.
- [ ] Мини-боссы (боссы Хильдир, лорд Рето отдельным боем).
- [ ] Генераторы щита Фейдера.
- [ ] Выделенный сервер: способ держать босса у одного модового клиента без HostOwner.

## Принципы, которые не меняются

- Только ванильные префабы, анимации, статус-эффекты и RPC — гость без мода должен
  видеть и чувствовать тот же бой.
- Ванильный бой (ИИ, атаки) не меняется, только дополняется.
- Любую механику можно выключить; любого босса можно вернуть в `Vanilla` без
  перезахода.
