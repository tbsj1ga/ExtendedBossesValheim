# ExtendedBosses

Raid-style boss fights for a group: HP phases, waves of adds, destructible
nests, biome mini-bosses as lieutenants, shields that drop when the adds die,
burn windows, marks, ground hazards, enrage and wipe reset - built only from
vanilla prefabs, animations and RPCs, so players without the mod see and feel
the same fight.

**Not released yet.** This package is a placeholder; the design lives in the
repository. Meant to run on the host together with HostOwner, which keeps the
boss and its adds owned by the host. Designed alongside WeaponArts.

Inspired by HardBosses (Nexus #877).

*Being designed with the help of an AI assistant (Claude by Anthropic); the
design decisions, verification against the game code and in-game testing are
the author's.*
